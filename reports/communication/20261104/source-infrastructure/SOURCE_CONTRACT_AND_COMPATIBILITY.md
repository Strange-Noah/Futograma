# Source contracts and migration compatibility

Contracts source-contract/1 separate requests, immutable raw artifacts, acquisition results and typed native observations. SourceService delegates network work to the existing public Client; source_parsing delegates extraction to existing provider parsers. Neither selects football subjects or grants canonical identity.

Logical identity excludes storage locations. Explicit roots, hash indexes and an existing verified asset reader resolve migrated archives. Captures preserve actual timestamp precision, request URL/parameters, response identity, status and body hash. Missing timestamps stay unknown; manual policy remains a distinct authority class and is never converted into an HTTP response or new authorization.

Outcome distinctions include NOT_REQUESTED, unresolved archive locator, required remote asset, integrity conflict, missing parser, identity mismatch, rate limitation, restriction and temporary failure. They cannot establish nonparticipation.

All 755 unique-per-club standardized historical records resolve to 54 distinct retained bodies. Nine existing private archives were hash verified through the established backend, without publishing their contents or identifiers. Repeated pure parsing gives 751 identical native identity/name/birth-date/club/scope/assertion records. Four articles yield metadata; their prior composite career/announcement identity bridges remain downstream decisions and are not inferred from expected names. Original records and facts are unchanged.

The 79 match bodies all verify and receive deterministic dispositions: 32 PARSED, 47 INCOMPLETE. Fifteen are saved web extracts, not native provider JSON. Eleven FotMob captures lack an independently retained requested ID. Nine parent/leaf competition relationships are retained separately. No identity is derived from an archive filename. Unknown bench participation is not silently converted to unused status: 164 prior UNUSED_SUBSTITUTE/zero observations become BENCH_PARTICIPATION_UNKNOWN/null in the source observation only. Another 1,172 source-key comparisons retain minutes and participation exactly. No stored football facts change.

The normal football browser export equals the reviewed baseline on the same frozen reference, excluding generated_at only. Database hash remains unchanged. The bounded live smoke test performed two anonymous requests (robots and official calendar), received HTTP 200 twice and parsed 47 native calendar rows. This verifies that transport path, not all provider availability. No collection schedule or production setting changed.

Replay entrypoints are ops.cloud.source_replay.replay and historical_replay. They accept explicit reference/archive/store/output arguments, use read-only SQLite and write only isolated observation reports. Raw sources, full observations, databases and assets remain private project-local evidence. Independent tests run without importing or executing reconstruction R1–R6.
