## Authority and duplication policy
Production remains governed by its current pinned code/data and existing entrypoints. Gate S may accept a reconstruction-canonical interface later; it cannot silently migrate production. Git preserves implementation versions; no copied v2/v3 pipeline directories are introduced. Existing historical one-off extractors, CacheSources, old LocalFotMob and cloud replay scripts have different callers/authority and are not assumed obsolete. RETIRED: none, because unused status and migration/rollback dependencies have not been proved.
